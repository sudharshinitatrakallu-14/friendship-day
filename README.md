# Friendship Day Secret Website 💙

## Files
- `index.html` — page structure
- `style.css` — design and animations
- `script.js` — secret codes and personalized messages

## Secret codes
- Soodhi
- veeee
- siri
- Junnu
- lala

## How to run
Open `index.html` in your browser.

## How to publish
Upload all three files to a GitHub repository and enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /(root)

Then share the GitHub Pages link with your friends.

## Important
This is a fun front-end "secret code" system, not real security. The messages are stored in `script.js`, so anyone who knows how to inspect the webpage could find them.
